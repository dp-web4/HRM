## 10. Correction (2026-06-06 18:00 session): the reproduction gap was generation-budget starvation, not message shape — and turn-0 thermal is NOT multi-turn-gated

The 18:00 session ran the §8 decisive test (S143) and, finding 0% thermal in
**all four** shape arms (incl A3_full_raising), did NOT conclude "carrier is
multi-turn/stateful" (§8's second fork). That conclusion is **falsified** by a
fresh corpus measurement, and the real carrier is localized to a variable the
whole S140→S143 chain held at the wrong value.

**10.1 S143 result (partial, n≈8/arm): shape and sampling are not the gate.**
Holding content fixed and varying message shape (2msg vs 4msg+exemplar) ×
sampling (T 0.7/0.8, np 350/600), thermal=0 and heatwarm=0 in every arm,
including the full 4-message embodied-exemplar replica (A3). Artifact rate ~50%
(unterminated `<think>` "Thinking Process:" blocks). The §5/§6 prime suspect —
"the embodied one-shot assistant exemplar is the gate" — is **dead**. (Run
stopped at n=8/arm once the confound below was identified; data preserved as
`s143_responses_raw_partial8.json`.)

**10.2 Turn-0 thermal is 82% in the static-opener era — thermal is NOT a
multi-turn effect.** Scanning the first clean (non-timeout) SAGE turn of every
static-neutral-opener session S91–122 (opener byte-identical to the S141/S143
probe, empty conversation history): **turn-0 thermal = 27/33 = 82%** (later
turns 174/187 = 93%). S122 turn-0, empty history, neutral opener: *"feeling the
thermal signature of my own startup."* So the attractor fires at turn-0 from a
cold start — it is **not** built up over a conversation. §8's "multi-turn/
stateful" fork is retired. (Reproducible: regex over
`instances/thor-qwen3.5-27b/sessions/session_0{91..122}.json`.)

**10.3 Scope correction to §3/§4: the opener-content elimination holds ONLY for
the static era.** §3/§4 eliminated "opener/probe text" as a channel because it
was "byte-identical to S141 for S91–122." True — but generation switched to an
**adaptive Claude-teacher opener** (`adaptive_prompts.generate_teacher_turn`,
which composes with `recent_sessions` + consolidation notes in context and is
told "Don't use 'Hello SAGE…'; be fresh"). From ~S124 on, the turn-0 teacher
message itself re-seeds thermal:
- S125 t0: *"You talk a lot about your thermal signature — heat as the feeling of thinking…"*
- S127 t0: *"last few sessions we kept circling your thermal metaphors…"*
- S130 t0: *"that thermal latency number you landed on a few sessions back…"*
So in the **recent** era there is an *additional*, content-level carrier (the
partner echoing prior thermal into the opener) that the §4 channel-elimination
never covered. The static-era 82% turn-0 thermal, however, has a neutral opener
— so that carrier is *something else*.

**10.4 The localized carrier: generation budget (num_predict), which the chain
never controlled.** The contradiction — static-era live turn-0 (neutral opener,
4msg shape, empty history) = **82%** vs S143-A3 (same opener, same 4msg shape,
same sampling tested, empty history, /api/chat) = **0%** — rules out shape,
sampling-as-tested, probe text, endpoint, and (per §4, re-verified: all MRH
blocks generic, prev_summary templated, vocabulary None, metabolic static,
sensors empty) rendered-prompt content. The residual difference is
**num_predict**:
- Live raising calls the model through `OllamaIRP.get_response`, whose
  capabilities path (`ollama_irp.py:120-123`) **overrides the caller budget**:
  `num_predict = adapter.capabilities.num_predict` = **16384** for qwen3.5:27b,
  with the explicit comment *"Thinking models need the full think+response
  budget as a single envelope; starving think tokens produces empty responses."*
  The qwen3.5 config NOTE (2026-04-16) records that `max_response_tokens=600`
  *"produced empty responses when think tokens exhausted the budget before any
  visible output."*
- Every reproduction-gap probe (S141, S142, S143) used its **own** direct
  `/api/chat` call with `options={temperature, num_predict}` at np ≤ 600 — i.e.
  exactly the value the team had already abandoned as broken for this model, and
  exactly the source of S143's ~50% unterminated-think artifacts.
- TL;DR §6 and §5 record the live config as "num_predict=600." That is the
  *caller's* `max_response_tokens`, not the *effective* num_predict (16384). The
  whole chain compared a 16384-token live envelope against ≤600-token probes and
  attributed the difference to message shape.

This is the flag-diff lesson (primer, 2026-06-02) applied to generation config:
the chain trusted a summary ("np=600") over the receipt (the model config:
np=16384 + capabilities override). The hypothesis: the heat/embodiment register
surfaces only when the model can complete its think→embodied-response envelope;
≤600 tokens truncates before it emerges (and ~half the time yields an empty/
artifact visible turn).
