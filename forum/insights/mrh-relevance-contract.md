# MRH as a Relevance Contract for SAGE

**Date:** 2026-08-17  
**Status:** cross-cutting insight / candidate framing  
**Source:** `dp-web4/Synchronism/forum/Markov_Relevancy_Horizon_as_Relevance_Contract.md`

A Synchronism Markov/coherence exploration has converged with several themes already central to SAGE: selective attention, identity persistence across model changes, organ replacement, memory compression, relationship context, and Web4 integration.

The refinement is:

> **MRH is a witness-relative contract over which distinctions still matter for the present question.**

That gives a more operational reading to something SAGE already does continuously: choose which parts of state, memory, relationship history, sensory detail, and model machinery remain active for the next inference.

## Identity is not the inventory of components

The arc began by asking how coherent entities emerge in Markov dynamics. It repeatedly found that a larger identity can persist while lower-level components change or disappear.

A useful provisional description became:

> **an emergent identity is a slow invariant under faster transformations that count as internal at the current MRH.**

That maps directly onto SAGE's identity-portability observations.

The model can change while recognizable identity persists. Organs can be swapped, prompts revised, memories compacted, and implementation details replaced without necessarily destroying the larger pattern.

The identity is therefore not simply the current component list.

It is closer to a relational invariant that recruits changing implementations into the same higher-scale process.

## Relations can themselves become entities

Another correction matters for SAGE's relational/developmental framing.

Strong positive coupling can produce stable alignment. Strong negative coupling can produce stable anti-alignment. Both are coherent relations.

So:

```text
interaction strength != interaction valence != interaction coherence
```

A persistent relation can itself become an entity-like slow variable.

Then the hierarchy is not merely:

```text
small things -> larger things
```

but:

```text
states -> persistent relations -> relations among relations
```

This seems directly relevant to SAGE relationship structure, federation, organism-level cognition, and the existing synthon framing. A higher-scale cognitive entity may be carried less by fixed members than by persistent relations among changing members/roles/contexts.

## Attention is an MRH operation

SAGE's cognition loop can be viewed as repeatedly constructing a temporary relevance contract.

For the current question:

- which observations matter?
- which memories matter?
- which relationship state matters?
- which organ outputs matter?
- which prior abstractions can be trusted as compressed input?
- which distinctions are safe to ignore right now?

That is an MRH decision whether or not it is named that way.

A higher MRH does not merely mean "more context." It can mean the opposite: **more justified forgetting of lower-level distinctions because a slower invariant has become sufficient.**

This is important for avoiding the common assumption that intelligence always improves by retaining more context.

Sometimes a better representation is one that preserves the relevant prediction while depending on fewer distinctions.

## Interior and exterior relevance

The arc also added an interior side to MRH.

The usual question is:

> how much of the exterior environment can be ignored?

But an emergent entity has another boundary:

> how much internal implementation detail can be ignored before prediction of the macro-identity suffers?

SAGE therefore sits naturally inside an informational shell:

```text
irrelevant micro-implementation
        -> retained slow identity / relations
        -> irrelevant distant context
```

This may be a useful way to think about memory compaction, organ interfaces, model replacement, and context assembly.

## Memory compression must remain re-expandable

A compressed memory or derived abstraction can be sufficient for today's question without being sufficient for every future question.

The governance side of the arc made this explicit: claim-specific proof bundles can safely omit unrelated history only because the authoritative provenance remains available when a later question expands the relevance horizon.

The SAGE analogue is straightforward:

> **compression is safe only relative to a question and a recovery path.**

A summary that has discarded details may be fully adequate for current cognition, but if a later task makes those details load-bearing, the organism needs some way to recover/reconstruct/re-query them or honestly report that it cannot.

## Evaluator/model replacement

The arc eventually applied component replacement to the evaluator itself.

Two model/evaluator versions can produce the same current answer while relying on different evidence/context.

So:

> **same answer does not imply same relevance horizon.**

This matters for SAGE because model swapping is already treated as normal implementation variation.

A replacement can preserve the visible response while changing:

- which memories it actually uses;
- which cues control its behavior;
- which latent assumptions activate;
- which context fields become load-bearing;
- how long a cached/derived conclusion remains semantically valid.

Therefore portability should eventually be evaluated on at least two axes:

1. behavioral/identity continuity at the relevant MRH;
2. dependency continuity: whether the new implementation relies on the same retained distinctions.

## A candidate SAGE relevance contract

The general structure emerging across Synchronism/Web4/Hestia can be adapted to cognition without prescribing an implementation:

```text
RelevanceContract {
    question / current task
    identity / relationship context
    active evaluator/model/organ plan
    state basis
    permitted evidence/context dependencies
    coverage / what is known to be omitted
    confidence/assurance basis
    lineage / prior state references
    re-expansion path
}
```

The important property is not the schema.

It is that the relevance boundary becomes inspectable rather than implicit.

## Connection to synthon framing

The synthon insight says that emergence is encouraged by placement rules rather than directly engineered.

This MRH refinement adds a complementary statement:

> **placement rules determine what relations can persist; relevance rules determine which of those persistent relations become effective entities for a witness/task.**

That may be one bridge between SAGE's developmental/relational work and the more formal Markov/coarse-graining picture.

## Compact formulation

For SAGE, the most useful short form may be:

> **Cognition is repeated construction and revision of a relevance horizon: retain what still changes the answer, compress what no longer does, and reopen the boundary when the task or stakes change.**

This is a candidate framing, not a claim of new mathematics or a proposed code change.
